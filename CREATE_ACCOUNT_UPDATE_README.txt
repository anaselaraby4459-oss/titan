تحديث إنشاء الحساب - Titan Academy

تم إضافة طلب إنشاء حساب في:
- الصفحة الرئيسية index.html
- صفحة الطالب student.html (موجودة مسبقاً وتم تحسين النص)
- صفحة ولي الأمر parent.html
- صفحة دخول الإدارة admin.html

كل الطلبات تُحفظ في:
tenants/{tenantId}/registration_requests

طريقة العمل:
1) الطالب/ولي الأمر يرسل الاسم + الكود + المستوى + رقم الهاتف.
2) الطلب يظهر في لوحة الإدارة > طلبات إنشاء الحساب.
3) عند الموافقة يتم إنشاء حساب Firebase Authentication للطالب تلقائياً.
4) الطالب وولي الأمر يدخلان بالكود ورقم الهاتف.

ملاحظة أمان:
لم يتم فتح إنشاء حساب إدارة عام بدون موافقة؛ إنشاء/صلاحيات الإدارة تظل من داخل لوحة الإدارة وقواعد Firebase فقط.
